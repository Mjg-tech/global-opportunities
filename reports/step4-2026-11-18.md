# Step 4 - evidence, cycles and views (2026-11-18)

Branch `upgrade/step-4-evidence`, built on `origin/main` after steps 0-3. Not committed.

## What was added

| Part | Where | What it does |
|---|---|---|
| Evidence files | `scripts/evidence.py`, `data/evidence/<id>.json` | Per-criterion eligibility (MET / NOT MET / UNKNOWN / NOT STATED, each with the organiser's sentence and page), funding line by line (who pays, amount, currency, conditions, out-of-pocket) and application cycles |
| Verdict ceiling | `evidence.derive_eligibility` | A record's `eligibility_for_me` can never be higher than its criteria allow; LIKELY needs the nationality rule read; an Africa-wide sentence does not prove the DRC |
| Judge gate | `scripts/judge.py` | `check` applies the evidence rules; `apply` re-reads every evidence quote on its page and drops the whole block (never the record) when one cannot be proven |
| Storage | `scripts/upsert.py` | Moves `evidence` out of the record, keeps earlier cycles, logs every changed assessment, funding line and cycle to the change log |
| Validation | `scripts/validate.py` | Checks every evidence file; refuses an `evidence` key inside a record |
| Cycles | `scripts/cycles.py`, `meta.upcoming` | Four states (confirmed current, expected next, historical, not yet announced); estimates are derived, labelled, and never written to a record |
| Weekly backlog | `scripts/scouts.py` | Three live records without criteria per channel per week, open and soonest-closing first |
| Site | `assets/js/views.js`, `app.js`, `explorer.js`, `dashboard.js` | Eleven preset views (`?view=`), "Upcoming to watch" panel, criteria / funding / cycle sections in the detail dialog |

## Pilot

Two records went through the real pipeline (batch, `judge.py check`, verdict, `judge.py apply` with the live quote check, `upsert`, `validate`): `turkiye-burslari-2027` (6 criteria, 6 funding lines, 1 cycle) and `pan-african-university-scholarships` (4 criteria, 1 funding line, 1 cycle). Every quote was found on its page. The verdict was written by the same session that wrote the evidence, so only the literal quote check was independent.

Findings the evidence layer surfaced:

- PAU nationality is `UNKNOWN`: the call says "African countries and the Diaspora" with no country list and does not name the DRC.
- PAU age limits depend on gender (25 male, 28 female), which the profile does not record: `UNKNOWN`.
- Türkiye Burslari accommodation: the summary says it is provided, but the detailed text confirms dormitory fees only for undergraduates. Recorded as paid by the organiser with the caveat in `conditions`; the record's `coverage.accommodation: Covered` rests on the same sentence.

## Honest limits

- Only 2 of 80 records have evidence. At 3 per channel per week it takes about six weekly cycles; each record costs a real page read.
- An estimate repeats last year's month. A programme that changes its calendar will be wrong; the organiser's own text always sits beside it.
- `Needs verification` (41 records) includes every PARTIALLY VERIFIED record, so it is broad by design.
- Priority categories from the pasted prompt (Part 12: EXCEPTIONAL ... FUTURE OPPORTUNITY) are not built: the transparent score is a separate decision.
